# Asteroids

A simple recreation of the classic Asteroids arcade game, developed using Python and Pygame as part of the **Build Asteroids** guided project on [Boot.dev](https://www.boot.dev/courses/build-asteroids-python).

## About the Project

This project was completed as part of my backend development coursework on Boot.dev.

The game involves controlling a spaceship, avoiding asteroids, and shooting them to survive.

The project focuses on practicing fundamental programming concepts, including:

- Object-oriented programming (OOP)
- Game loops and user input
- Collision detection
- Vector-based movement
- Game state management

## Technologies Used

- Python
- Pygame
- uv (Python package and environment management)

## Running the Game

**Requirements:** Python 3.13 and uv.

1. Clone the repository:

   ```bash
   git clone https://github.com/SebastianKlemkosky/asteroids.git
   cd asteroids
   ```

2. Install the project dependencies:

   ```bash
   uv sync
   ```

3. Start the game:

   ```bash
   uv run main.py
   ```
